Userscript managers

Capabilities to retain or improve from ScriptCat, Violentmonkey and Tampermonkey ecosystems.

Compatibility is a product feature

Torsionfield must support metadata blocks, match/include semantics, grants, resources, update URLs, script ordering, enable state and import/export without treating existing user libraries as disposable.

Migration rules

  • Import is non-destructive and creates a signed migration report.
  • Original managers are not disabled or uninstalled automatically.
  • Unsupported grants are surfaced before activation.
  • Duplicate identity is resolved through update, fork, replace or error policy.
  • Script source, metadata and provenance remain exportable.

Where Torsionfield goes further

Transactional mutation, typed CAT APIs, operation-scoped routing, visual compilation, evidence, adapter health, workspace restoration, local-tool endpoints and NetworkScripts become native concepts instead of ad hoc userscript conventions.
