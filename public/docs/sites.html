First-party sites and background integration

How torsionfield.de and the Transductive domains cooperate with the extension and cloud control plane.

torsionfield.de

Canonical product site for downloads, signed manifests, documentation, registration, pairing, devices, nodes, endpoints, project memberships, marketplace metadata, Prompt Commit provenance, security advisories and status.

transductive.org

Commons and participatory-development layer: community profiles, collaborative projects, public workflows, NetworkScript discovery and crowdcoding coordination.

transductive.science

Research application: task definitions, evidence contracts, replicated execution, datasets, result comparison, provenance, peer review and publication capsules.

transductive.art

Creative application: media pipelines, collaborative productions, versioned prompt/script compositions, reusable project packs and optional peer tools.

FirstPartySiteAdapter

These sites use a signed, versioned protocol instead of fragile scraping. The bridge handles pairing challenges, project membership, task exchange, artifact references, endpoint publication, health and opening extension workspaces. Origin and message signatures are verified before privileged actions.

Torsionfield Runtime

Local-first browser automation, userscripts, agents, workflows and peer capabilities. Alpha product architecture — 31 July 2026.
