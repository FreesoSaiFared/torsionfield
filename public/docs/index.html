What Torsionfield is

Torsionfield Runtime is a local-first operating layer for programmable browser work. It combines a ScriptCat-derived userscript manager, provider adapters, protected agent tabs, a visual Operation Graph, a local Torsion Node daemon and optional peer/cloud coordination.
