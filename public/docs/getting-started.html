Getting started

The intended installation, migration and first-success journey for an automation enthusiast.

Executable today

Install the Local Repomix ChatGPT app and invoke one bounded repository or directory operation. The machine-local service owns execution; ChatGPT receives the declared result and evidence. Peer sharing is not yet enabled.

Target three-minute path — not yet released

  1. Install the signed Torsionfield Extension.
  2. Import ScriptCat, Violentmonkey or Tampermonkey scripts without mutating the original manager.
  3. Open a page and choose Record or Agentify this site.
  4. Run the generated automation in review mode and inspect the Perceive–Plan–Act–Verify ledger.
  5. Install Torsion Node only when local files, processes, models, MCP or peer work is needed.

First success criterion

A new user must complete one useful automation without writing code, registering an account or installing the daemon. Registration and networking are optional upgrades.
