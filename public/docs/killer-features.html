Killer features

The features intended to make Torsionfield preferable even without its daemon or peer network.

Record once, compile three ways

The same typed Operation Graph produces a visual workflow, maintainable userscript and callable endpoint. Editing any representation updates the shared model instead of creating three incompatible automation engines.

Agentify this site

A page plus a stated goal launches target selection, trace capture, script generation, reversible tests and installation. The resulting capability can remain private, become a local tool or be exposed as a NetworkScript.

Self-healing scripts

Selectors are candidates, not timeless facts. Torsionfield combines stable attributes, roles, accessible names, editor markers, ancestor relation, historical success, DOM-shape fingerprints and optional vision. Ambiguity stops unattended action or invokes explicit user selection.

Universal productivity layer

  • Command palette and keyboard link hints across scripts, tabs, agents, workflows and peers.
  • Time-travel workspaces with tab groups, scripts, bindings and in-flight state.
  • Reproducible Web Capsules containing page state, prompts, code, adapter revisions and evidence.
  • Multi-provider routing across web sessions, APIs, local models and MCP.
  • Visual trust ledger showing perception, decision, action and verification.
  • Signed marketplace metadata with permissions, provenance and drift health.
