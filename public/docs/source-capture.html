Capture, keyboard control and sessions

The incorporation path for SingleFile, Vimium and session-management capabilities.

Reproducible Web Capsules

Single-file page capture inspires a larger capsule: document state, fetched resources, selected storage, scripts, prompts, operation graph, adapter revision, screenshots, traces and result evidence. Secrets and cookies are excluded unless an explicit export profile says otherwise.

Universal command palette

Vimium-style keyboard control should reach links, page actions, scripts, workflows, agent tabs, endpoints and project commands. Link hints become a user-directed target-selection primitive that can also generate stable selector evidence.

Time-travel workspaces

Session managers show the value of restoring windows and tabs. Torsionfield extends the snapshot with tabInstanceId, agentId, script versions, adapter health, workflow state and unresolved operations. Restore never blindly repeats uncertain effects.

Capsule provenance

Each capsule is content-addressed and includes a manifest of included and deliberately omitted state. A verifier can reproduce the automation environment without trusting an unstructured screen recording.
